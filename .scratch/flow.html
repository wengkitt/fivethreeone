Cookie flow: session_token is httpOnly, secure, SameSite=Lax. Worker reads it from the Cookie header, validates against the session table, and sets userId, lifterId, username on the Hono context.

Request / Response Details

POST /api/blocks — Create Block

Request { squat: { weight: 100, reps: 5 }, bench_press: { weight: 80, reps: 5 }, deadlift: { weight: 140, reps: 5 }, overhead_press: { weight: 50, reps: 5 } } Worker → validate no active block Worker → estimate1RM → calculateTmFromOneRm D1 → INSERT block Response { success: true, data: { id, status: "active", ... } }

GET /api/blocks/:id — Block Detail

Worker → auth check (cookie → session) D1 → SELECT block D1 → SELECT workout_days Worker → group by cycle → week @core → generateWorkoutSets(tm, week) Response { success: true, data: { block, workoutDays } }

POST /api/blocks/:id/tick — Complete Day

Request { lift: "squat", cycleNumber: 1, weekNumber: 2 } D1 → UPSERT workout_day D1 → COUNT completed+skipped Worker → if count ≥ 64 → complete block Response { success: true, data: { completed: true } }

GET /api/auth/session — Session Check

Request Cookie: session_token=abc123 D1 → SELECT session WHERE token = ? Worker → check expires_at > now Response { success: true, data: { userId, lifterId, username } }

Database Schema (D1 / SQLite)

erDiagram user ||--o{ session : has user ||--|| lifter : has user ||--o{ account : has lifter ||--o{ block : trains block ||--o{ workout_day : contains user { text id PK text name text email UK boolean email_verified text image "nullable" timestamp created_at timestamp updated_at } session { text id PK text token UK timestamp expires_at text user_id FK text ip_address "nullable" text user_agent "nullable" } account { text id PK text user_id FK text provider_id "'credential'" text password "PBKDF2 hash" } lifter { text id PK text user_id FK UK text username UK text weight_unit "'kg' | 'lb'" int plate_increment "x100, default 2500" } block { text id PK text lifter_id FK text status "'active' | 'completed'" real squat_weight int squat_reps real bench_press_weight int bench_press_reps real deadlift_weight int deadlift_reps real overhead_press_weight int overhead_press_reps } workout_day { text id PK text block_id FK text lift "squat | bench_press | deadlift | overhead_press" int cycle_number "1-4" int week_number "1-4" text status "'pending' | 'completed' | 'skipped'" timestamp completed_at "nullable" }
Auth tables (user, session, account, verification) follow the Better Auth schema. Domain tables (lifter, block, workout_day) are custom. Password hashing: PBKDF2-SHA256, 100k iterations, format salt:derivedKey.

Epley formula: 1RM = weight × reps × 0.0333 + weight
Training Max: TM = floor(1RM × 0.9 ÷ plateInc) × plateInc
Working weight: weight = floor(TM × % ÷ plateInc) × plateInc
Cycle TM progression: each cycle applies progressTm cumulatively. + suffix on reps = AMRAP (as many reps as possible).
